## Areas for Improvement

Although I achieved the main learning and project objectives, I identified several areas that I should continue improving:

* **Strengthen technical depth.** I need to develop a deeper understanding of Machine Learning model optimization, NLP techniques, cloud architecture, and the trade-offs between system performance, scalability, and operational cost.
* **Improve problem-solving efficiency.** I should adopt a more systematic approach to debugging by defining hypotheses, collecting evidence from logs and metrics, and evaluating solutions based on measurable results.
* **Enhance communication skills.** I need to improve my ability to explain technical concepts concisely, present project progress more clearly, and communicate effectively in both everyday and professional contexts.
* **Improve planning and time management.** I should break larger tasks into smaller milestones, identify potential risks earlier, and allocate more time for testing and system optimization.
* **Develop stronger production-oriented practices.** I plan to improve my knowledge of automated testing, CI/CD, security, monitoring, infrastructure management, and cloud cost optimization to prepare for real-world software and cloud engineering roles.

Overall, the First Cloud AI Journey program provided me with valuable experience in applying cloud and AI knowledge to a practical project. The program helped me connect individual technical concepts into a complete development workflow and gave me a clearer understanding of the skills and professional practices required for future work in Cloud, AI, and software engineering.
