### Week 4: Exploring NLP Models and Selecting an Approach for the Problem

**Duration:** 01/06/2026 – 07/06/2026

#### Objectives

* Explore NLP models and fine-tuning methods for text classification
* Practice training and evaluating models using notebooks
* Select a suitable model or approach for the project
* Learn how to package a Machine Learning model into a Docker image

#### Tasks Completed

* Studied advanced Machine Learning and NLP concepts, focusing on natural language processing models and fine-tuning methods for pre-trained models
* Learned about model evaluation metrics, including Accuracy and F1-score, and explored how these metrics can be used to evaluate classification performance
* Practiced using notebooks by preparing the training environment, running the training process, and examining the model outputs
* Compared the results of different models or approaches to identify the most suitable solution for the project requirements
* Explored how to package a Machine Learning model together with its required libraries and runtime environment into a Docker image to support deployment

#### Results Achieved

* Developed an understanding of the role of NLP models and fine-tuning methods in text classification
* Learned how to use Accuracy and F1-score to evaluate model performance
* Selected a suitable model or approach for the project problem
* Understood the basic process of packaging a Machine Learning model into a Docker image and preparing it for deployment
