### Week 10: AWS Resource Cleanup and Cost Control

**Duration:** 13/07/2026 – 19/07/2026

#### Objectives

* Learn how to manage and clean up AWS resources after testing or project acceptance
* Practice setting budgets and cost alerts to control AWS spending
* Create a script or guideline to support the resource cleanup process
* Complete the system report and technical documentation

#### Tasks Completed

* Reviewed the AWS resources used during development and identified resources that were no longer required to prevent unexpected costs
* Learned how to delete or release resources after testing was completed, including services and components created during deployment
* Practiced setting up AWS Budgets and configuring alerts when spending reached predefined thresholds
* Created a script or step-by-step guideline to support systematic resource review and cleanup
* Documented the development process, system architecture, technologies used, and project results in the final report and technical documentation

#### Results Achieved

* Understood the importance of resource cleanup and cost control after project completion
* Learned how to review, identify, and remove AWS resources that were no longer required
* Learned how to set up budgets and cost alerts to monitor service usage and spending
* Completed the technical documentation and summary report for the system
