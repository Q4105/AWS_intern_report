### Week 2: Exploring Serverless Architecture with AWS

**Duration:** 18/05/2026 – 24/05/2026

#### Objectives

* Understand the roles of Amazon API Gateway, AWS Lambda, and Amazon DynamoDB in a serverless architecture
* Practice building and deploying a simple serverless application on AWS
* Continue learning Docker by building images and running containers in a local environment

#### Tasks Completed

* Studied Amazon API Gateway, AWS Lambda, and Amazon DynamoDB, and learned how these services work together to build applications without directly managing servers
* Created a simple Lambda function and became familiar with the process of writing, configuring, and deploying code using AWS Lambda
* Connected the Lambda function to Amazon API Gateway to create an API that can receive requests and return responses
* Deployed a serverless “Hello World” demo, tested API requests, and verified that the Lambda function processed requests successfully
* Practiced building a Docker image from a simple application and running a container locally to become familiar with the application packaging and execution workflow

#### Results Achieved

* Understood the roles of Amazon API Gateway, AWS Lambda, and Amazon DynamoDB in a serverless architecture
* Successfully created a Lambda function, connected it to API Gateway, and deployed a basic serverless API
* Completed the “Hello World” demo and verified that requests were successfully routed from API Gateway to Lambda
* Learned how to build Docker images and run containers in a local environment
