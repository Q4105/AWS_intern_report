### Tuần 2: Khám phá kiến trúc Serverless với AWS

**Thời gian:** 18/05/2026 – 24/05/2026

#### Mục tiêu

* Tìm hiểu vai trò của Amazon API Gateway, AWS Lambda và Amazon DynamoDB trong kiến trúc serverless
* Thực hành xây dựng và triển khai một ứng dụng serverless đơn giản trên AWS
* Tiếp tục học Docker thông qua việc build image và chạy container trên môi trường cục bộ

#### Công việc đã thực hiện

* Học về Amazon API Gateway, AWS Lambda và Amazon DynamoDB; tìm hiểu cách các dịch vụ này phối hợp để xây dựng ứng dụng mà không cần quản lý trực tiếp máy chủ
* Tạo một Lambda function đơn giản và làm quen với quy trình viết, cấu hình và triển khai mã nguồn trên AWS Lambda
* Kết nối Lambda function với API Gateway để tạo API có thể nhận request và trả về response
* Triển khai demo serverless “Hello World”, kiểm tra khả năng gọi API và xác nhận Lambda xử lý request thành công
* Thực hành build Docker image từ ứng dụng đơn giản và chạy container trên máy cục bộ để làm quen với quy trình đóng gói và thực thi ứng dụng

#### Kết quả đạt được

* Hiểu được vai trò của API Gateway, Lambda và DynamoDB trong một kiến trúc serverless
* Có thể tạo Lambda function, kết nối với API Gateway và triển khai một API serverless cơ bản
* Hoàn thành demo “Hello World” và xác nhận luồng request từ API Gateway đến Lambda hoạt động đúng
* Biết cách build Docker image và chạy container trên môi trường cục bộ
