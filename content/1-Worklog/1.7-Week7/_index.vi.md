### Tuần 7: Đóng gói và triển khai ứng dụng bằng Docker

**Thời gian:** 22/06/2026 – 28/06/2026

#### Mục tiêu

* Củng cố kiến thức Docker thông qua quy trình build, kiểm thử và quản lý Docker image
* Thực hành đóng gói mô hình Machine Learning hoặc dịch vụ backend vào container
* Tìm hiểu cách lưu trữ và quản lý Docker image trên Amazon ECR
* Áp dụng các Dockerfile best practices để tối ưu kích thước image

#### Công việc đã thực hiện

* Thực hành build Docker image, chạy container trên môi trường cục bộ và kiểm tra hoạt động của ứng dụng trước khi triển khai
* Đóng gói mô hình Machine Learning hoặc dịch vụ backend cùng các thư viện và môi trường cần thiết vào Docker container
* Tìm hiểu quy trình đăng nhập Amazon ECR, gắn tag và push Docker image lên ECR để lưu trữ và chuẩn bị cho quá trình triển khai
* Nghiên cứu các Dockerfile best practices, bao gồm sắp xếp các layer hợp lý, tận dụng cơ chế cache và chỉ đưa các thành phần cần thiết vào image
* Tìm hiểu các phương pháp giảm kích thước Docker image nhằm rút ngắn thời gian build, push, pull và cải thiện hiệu quả triển khai

#### Kết quả đạt được

* Có thể build, chạy và kiểm thử Docker image trên môi trường cục bộ
* Hoàn thành việc đóng gói mô hình hoặc dịch vụ backend thành Docker image có thể sử dụng cho quá trình triển khai
* Biết cách gắn tag và push Docker image lên Amazon ECR
* Hiểu được các nguyên tắc cơ bản trong việc viết Dockerfile hiệu quả và tối ưu kích thước image
