### Week 7: Containerizing and Deploying Applications with Docker

**Duration:** 22/06/2026 – 28/06/2026

#### Objectives

* Strengthen Docker knowledge through the process of building, testing, and managing Docker images
* Practice containerizing a Machine Learning model or backend service
* Learn how to store and manage Docker images using Amazon ECR
* Apply Dockerfile best practices to optimize image size

#### Tasks Completed

* Practiced building Docker images, running containers in a local environment, and testing application functionality before deployment
* Packaged a Machine Learning model or backend service together with its required libraries and runtime environment into a Docker container
* Learned how to authenticate with Amazon ECR, tag Docker images, and push them to ECR for storage and deployment preparation
* Studied Dockerfile best practices, including organizing layers efficiently, leveraging build caching, and including only the necessary components in an image
* Explored methods for reducing Docker image size to shorten build, push, and pull times and improve deployment efficiency

#### Results Achieved

* Successfully built, ran, and tested Docker images in a local environment
* Containerized a Machine Learning model or backend service into a Docker image ready for deployment
* Learned how to tag and push Docker images to Amazon ECR
* Understood the fundamental principles of writing efficient Dockerfiles and optimizing Docker image size
