### Tuần 9: Tích hợp quy trình xử lý End-to-End

**Thời gian:** 06/07/2026 – 12/07/2026

#### Mục tiêu

* Tìm hiểu quy trình xử lý end-to-end từ frontend đến API, mô hình Machine Learning và cơ sở dữ liệu
* Thực hành kết nối ứng dụng frontend với API Gateway và AWS Lambda
* Hoàn thành luồng hoạt động cơ bản của hệ thống
* Tìm hiểu cách kiểm thử API, theo dõi log và xử lý lỗi

#### Công việc đã thực hiện

* Nghiên cứu luồng xử lý end-to-end của hệ thống, bao gồm quá trình gửi dữ liệu từ frontend đến API, xử lý dữ liệu bằng mô hình Machine Learning và lưu hoặc truy xuất kết quả từ cơ sở dữ liệu
* Kết nối ứng dụng frontend với Amazon API Gateway để gửi request đến AWS Lambda và nhận kết quả xử lý từ backend
* Kiểm tra khả năng truyền dữ liệu giữa các thành phần và xác nhận kết quả được trả về đúng định dạng để frontend có thể hiển thị
* Thực hành kiểm thử API bằng các request mẫu, kiểm tra response và xác minh hoạt động của các endpoint
* Sử dụng CloudWatch Logs để theo dõi quá trình thực thi của Lambda, xác định nguyên nhân và xử lý các lỗi phát sinh trong quá trình tích hợp

#### Kết quả đạt được

* Hiểu được luồng hoạt động end-to-end từ frontend đến API, mô hình Machine Learning và cơ sở dữ liệu
* Kết nối thành công frontend với API Gateway và AWS Lambda
* Hoàn thành demo cơ bản với luồng gửi dữ liệu, xử lý bằng backend và trả kết quả về frontend
* Biết cách kiểm thử API, theo dõi log và hỗ trợ debug lỗi trong quá trình tích hợp
