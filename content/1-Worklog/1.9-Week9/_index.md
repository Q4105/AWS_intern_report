### Week 9: Integrating the End-to-End Application Workflow

**Duration:** 06/07/2026 – 12/07/2026

#### Objectives

* Understand the end-to-end workflow from the frontend to the API, Machine Learning model, and database
* Practice connecting the frontend application to Amazon API Gateway and AWS Lambda
* Complete the basic system workflow
* Learn how to test APIs, review logs, and debug integration issues

#### Tasks Completed

* Studied the system's end-to-end workflow, including sending data from the frontend to the API, processing the data using a Machine Learning model, and storing or retrieving results from the database
* Connected the frontend application to Amazon API Gateway to send requests to AWS Lambda and receive processing results from the backend
* Tested data transmission between system components and verified that the returned results followed a format that could be displayed by the frontend
* Practiced testing APIs using sample requests, reviewing responses, and verifying endpoint functionality
* Used CloudWatch Logs to monitor Lambda execution, identify the causes of issues, and debug errors that occurred during integration

#### Results Achieved

* Understood the end-to-end workflow from the frontend to the API, Machine Learning model, and database
* Successfully connected the frontend to Amazon API Gateway and AWS Lambda
* Completed a basic demonstration workflow that sends data, processes it through the backend, and returns the results to the frontend
* Learned how to test APIs, review logs, and support debugging during system integration
