### Week 1: Introduction to AWS and Docker Fundamentals

**Duration:** 11/05/2026 – 17/05/2026

#### Objectives

* Become familiar with core AWS services and understand the roles of IAM, S3, EC2, and VPC
* Practice access management, data storage on AWS, and local environment configuration using the AWS CLI
* Learn the fundamental concepts of Docker and container technology

#### Tasks Completed

* Studied core AWS services, including IAM, S3, EC2, and VPC, and learned how they are used for identity and access management, data storage, computing resources, and network infrastructure
* Created an IAM user, configured access permissions, and used the IAM user instead of the root account for daily tasks
* Installed and configured the AWS CLI to connect the local environment to an AWS account
* Created an S3 bucket and practiced uploading and downloading data while becoming familiar with AWS storage resource management
* Learned the fundamental concepts of Docker and containers, including how containers package applications together with their runtime environments

#### Results Achieved

* Understood the login process and how to manage access permissions using IAM users
* Successfully configured the AWS CLI and performed basic S3 operations, including creating buckets and uploading and downloading data
* Developed a foundational understanding of the roles of IAM, S3, EC2, and VPC within the AWS ecosystem
* Gained basic knowledge of Docker and understood the role of containers in application deployment
