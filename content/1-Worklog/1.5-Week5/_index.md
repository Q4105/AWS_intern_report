### Week 5: Deploying a Frontend Application on AWS

**Duration:** 08/06/2026 – 14/06/2026

#### Objectives

* Learn about AWS services used to deploy and distribute web applications
* Practice deploying a simple frontend application on AWS
* Learn how to configure CORS and manage environment variables during deployment

#### Tasks Completed

* Studied AWS Amplify, Amazon S3 Hosting, and Amazon CloudFront, and learned the role of each service in deploying, hosting, and distributing web applications
* Explored the frontend deployment workflow using AWS Amplify and the use of Amazon S3 to host the application's static assets
* Built and deployed a simple frontend application on AWS, then verified that the application was accessible in the deployed environment
* Learned how to configure CORS to allow the frontend to communicate with APIs or backend services hosted on a different domain
* Practiced using environment variables to manage configuration values, such as API endpoints, without hardcoding them directly into the source code

#### Results Achieved

* Understood the roles of AWS Amplify, Amazon S3, and Amazon CloudFront in deploying and distributing web applications
* Successfully deployed a simple frontend application and ran it on AWS
* Learned how to configure CORS to support communication between the frontend and backend
* Understood how to use environment variables to manage application configuration more flexibly and securely
