### Tuần 5: Triển khai Frontend trên AWS

**Thời gian:** 08/06/2026 – 14/06/2026

#### Mục tiêu

* Tìm hiểu các dịch vụ AWS hỗ trợ triển khai và phân phối ứng dụng web
* Thực hành triển khai một ứng dụng frontend đơn giản lên AWS
* Tìm hiểu cách cấu hình CORS và quản lý environment variables trong quá trình triển khai

#### Công việc đã thực hiện

* Học về AWS Amplify, Amazon S3 Hosting và Amazon CloudFront; tìm hiểu vai trò của từng dịch vụ trong việc triển khai, lưu trữ và phân phối ứng dụng web
* Tìm hiểu quy trình triển khai ứng dụng frontend bằng AWS Amplify và cách sử dụng S3 để lưu trữ các tài nguyên tĩnh của ứng dụng
* Thực hành build và deploy một ứng dụng frontend đơn giản lên AWS, sau đó kiểm tra khả năng truy cập ứng dụng thông qua môi trường được triển khai
* Tìm hiểu cách cấu hình CORS để cho phép frontend giao tiếp với các API hoặc dịch vụ backend từ một domain khác
* Thực hành sử dụng environment variables để quản lý các thông tin cấu hình, chẳng hạn như API endpoint, mà không cần ghi trực tiếp các giá trị này vào mã nguồn

#### Kết quả đạt được

* Hiểu được vai trò của AWS Amplify, Amazon S3 và Amazon CloudFront trong việc triển khai và phân phối ứng dụng web
* Hoàn thành việc triển khai một ứng dụng frontend đơn giản và chạy thành công trên AWS
* Biết cách cấu hình CORS để hỗ trợ giao tiếp giữa frontend và backend
* Hiểu được cách sử dụng environment variables để quản lý cấu hình ứng dụng linh hoạt và an toàn hơn
