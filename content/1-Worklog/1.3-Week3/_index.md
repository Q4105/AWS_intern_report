### Week 3: Exploring Machine Learning and Its Application to Text Classification

**Duration:** 25/05/2026 – 31/05/2026

#### Objectives

* Learn the fundamental concepts of Machine Learning and supervised learning
* Explore how Machine Learning models can be applied to the text classification problem in the project
* Learn how to containerize a Machine Learning application using Docker

#### Tasks Completed

* Studied the fundamental concepts of Machine Learning, with a focus on supervised learning and how models learn from labeled data
* Explored text classification, the main steps involved in building a classification model, and how input data is used to predict labels
* Reviewed Machine Learning documentation, examined datasets, and studied data preprocessing techniques before model training
* Learned the machine learning training pipeline, including data preparation, model training, evaluation, and prediction
* Explored how to containerize a Machine Learning application using Docker to create a consistent and portable runtime environment

#### Results Achieved

* Developed a foundational understanding of supervised learning and its application to text classification
* Understood the main stages of a machine learning training pipeline, from data preparation and preprocessing to model training and evaluation
* Created an initial plan for integrating a Machine Learning model into the project
* Understood the role of Docker in packaging Machine Learning applications and maintaining a consistent runtime environment
