### Week 6: Monitoring Services and Applying Basic Security Practices on AWS

**Duration:** 15/06/2026 – 21/06/2026

#### Objectives

* Learn about logging and monitoring tools on AWS
* Practice collecting logs, monitoring metrics, and configuring alerts for AWS services
* Learn how to use IAM roles and apply the principle of least privilege

#### Tasks Completed

* Studied Amazon CloudWatch, CloudWatch Logs, Metrics, and Alarms, and learned how these tools support monitoring the health and performance of AWS services
* Enabled logging for AWS Lambda and reviewed execution logs in CloudWatch Logs to monitor function behavior and support troubleshooting
* Practiced monitoring basic Lambda metrics and created a CloudWatch Alarm to detect and send alerts when a metric exceeded a defined threshold
* Learned how to use IAM roles to grant AWS services access to required resources without storing credentials directly in the source code
* Studied the principle of least privilege and how to grant users or services only the permissions required to perform their tasks

#### Results Achieved

* Understood the roles of CloudWatch Logs, Metrics, and Alarms in monitoring AWS services
* Successfully enabled Lambda logging, reviewed logs, and created a basic alarm based on service metrics
* Learned how to use CloudWatch to monitor service activity and support issue detection
* Understood the role of IAM roles and the principle of least privilege in improving system security
